# Project Guide
> This project is a simple Landing Page designed using TailwindCSS for styling, with additional JavaScript libraries such as Swiper and Animate.CSS for enhanced functionality and animation effects. The result is a visually appealing and engaging web page that is sure to grab the attention of visitors.

## To start project
```
npm run dev
```

## To bundle JavaSript code
```
npm run webpack
```


## To regenerate css using TailwindCSS
```
npm run style
```
